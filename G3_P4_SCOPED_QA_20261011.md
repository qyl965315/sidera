## Implemented machine behavior

- An automatic Antigravity declaration no longer creates an `installed://`
  Session placeholder. It requires a non-placeholder native stream-json
  conversation locator and an explicitly selected listed model.
- Configuration still creates neither Presence, a Grant, nor a ModelBinding.
  An Antigravity `--model` request is only a preference: the adapter requires
  the native `init.model` attestation, and rejects turns if it is absent or
  differs from the reviewed provider/model pair.
- `antigravity-enrollment-review` is a server-held, native-dialog review. It
  requires the same Human who owns the current reviewed local permission
  package, records the exact existing locator and selected model, and is
  consumed only once at Core start.
- Generic session onboarding then opens/locates that exact existing Host,
  compares the adapter attestation with the reviewed model, and invokes the
  normal authorized `IdentityStore.bindModel` action. It never inserts a
  binding directly. A mismatch, missing grant, missing authentication, or
  uncertain lookup becomes durable `blocked`; a later start does not retry.
- `native-chief-review` binds `sidera-native://local/<chiefNodeId>` through
  the normal Human-reviewed Chief binding path. It does not fabricate a
  ChatGPT cloud return, Presence, or external route.
- The native first-use UI is available at `/first-use`; it uses only typed
  local endpoints and the existing Electron native approval dialog. It has no
  model-login workaround and leaves the user at HOLD if native verification is
  unavailable.

## Focused negative coverage

`tests/local-setup.test.ts` now verifies that first enrollment:

1. rejects an `installed://` locator;
2. rejects enrollment before an approved local Human grant;
3. rejects a second Human even if that Human belongs to the same World;
4. keeps both `model_bindings` and `sessions` empty before native enrollment;
5. persists the reviewed exact locator/model only after confirmation; and
6. cannot be proposed again after the one review has been recorded.

`tests/antigravity.test.ts` also verifies that an explicit configured model is
not sufficient: native `init.model` is required for turns.
